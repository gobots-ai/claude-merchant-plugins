# GoBots plugins para o Claude

Plugins do Claude para lojistas do Mercado Livre que usam a GoBots.

| Plugin | O que faz |
|---|---|
| [`gobots`](plugins/gobots) | Conecta o Claude à sua conta GoBots: lojas, Product Ads, catálogo, promoções, recomendações e atendimento. |

## Instalação no Claude Code

```sh
/plugin marketplace add gobots-ai/claude-merchant-plugins
/plugin install gobots@gobots
```
